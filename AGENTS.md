# AGENTS.md — working agreement for this repo

The agreement lives in **[CLAUDE.md](CLAUDE.md)**. Read it now, before anything
else, and follow it as written.

**Why a pointer and not a copy.** This file *was* a copy — 345 lines identical
to CLAUDE.md except for the assistant it addressed. Two copies of a living
document drift the moment either one is edited, and nothing catches it: a
session reading the stale half confidently follows a retired rule, and every
change to the agreement has to be remembered twice. One file, two doors.

Two things to carry across as you read it:

- **Instructions addressed to "Claude" are addressed to you.** The file names
  one assistant because it grew up beside one. Every rule in it is about
  working in *this repo* — the session-start bootstrap, the build → hand off →
  approve → commit loop, the release ritual, the code conventions — and none of
  it depends on which model is doing the work.
- **The `Co-Authored-By` trailer names the model actually writing the commit,**
  so it names yours. CLAUDE.md states the rule in terms of Claude models
  because that is what has been writing them; the rule is "don't copy an old
  commit's trailer verbatim", and it applies unchanged.
